Open Commando

A browser build of the game engine source code released by EA under the GPL. Not affiliated with or endorsed by Electronic Arts. Plays with your own copy of the game's data. Source code (GPL v3 with EA's additional terms).
Checking game data…
Pick the folder where the game is installed (the one with the Data folder inside). On Steam: Library → right-click the game → Manage → Browse local files.
The files (about 1.3 GB) are copied once into this browser's private storage. Nothing is uploaded.
Forget game files
Click the game to capture the mouse · Alt+Enter: fullscreen (keeps Ctrl and Esc in the game) · Alt+F: frame rate
